# Controle-de-Estoques-em-C
Controle de estoques na linguagem C, com funções simples e funcionais

Criado por Ana Carolina, aprimorado para o Projeto Final, da Sprint Behring Academy

-Comandos usados
Switch;
Do-While;
Biblioteca string.h;
Funções com .FILE;

O que o código faz?
Adiciona e remove itens;
Lista o estoque e permite pesquisa;
Ao adicionar itens, pode-se informar
 Nome
 Quantidade
 ID
 Preço
Ao listar estoque, é apresentada essas 4 informações e o valor total do lote de cada item.

**Funções extras
Biblioteca <windows.h> e <ctype.h>, junto ao comando "SetConsole" foram adicionadas para permitir palavras com acentos ou "ç"
Uso da função "limpar_buffer" evita que "\n" fique preso á memoria do computador, podendo gerar bugs.
Uso de Atoi e Atof para converter strings em numeros.
